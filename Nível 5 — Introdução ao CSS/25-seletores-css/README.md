# 25 — Seletores CSS

## Sobre o exercício

Explorar seletores de elemento, classe, ID, agrupamento e descendência.

## Tecnologias

- HTML5
- CSS3

## Estrutura

`index.html` — laboratório de seletores
- `assets/css/style.css` — regras CSS
- `assets/img/conta-gotas.png` — imagem de referência

## Conceitos praticados

Seletores `p`, `.classe` e `#id`; agrupamento `h1, h2`; seletor descendente `.card p`; especificidade na prática.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo HTML principal em um navegador moderno.
