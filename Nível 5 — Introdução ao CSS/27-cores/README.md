# 27 — Cores em CSS

## Sobre o exercício

Exibir as principais formas de declarar cores na web em uma coleção de blocos visuais.

## Tecnologias

- HTML5
- CSS3

## Estrutura

`cores.html` — laboratório de cores
- `assets/css/style.css` — declarações de cor
- `assets/img/cores.jpg` — imagem de referência

## Conceitos praticados

Nomes de cor; hexadecimal; `rgb()`; `rgba()` com transparência; `hsl()`; classes reutilizáveis e layout inline-block.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo HTML principal em um navegador moderno.
