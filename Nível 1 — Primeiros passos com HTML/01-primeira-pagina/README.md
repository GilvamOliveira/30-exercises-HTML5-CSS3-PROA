# 01 — Primeira Página

## Sobre o exercício

Construir uma primeira página HTML apresentando o autor e os elementos estruturais essenciais de um documento web.

## Tecnologias

- HTML5
- CSS3

## Estrutura

`index.html` — página principal
- `assets/css/style.css` — folha de estilos vinculada
- `assets/img/primeira pagina.png` — imagem de referência

## Conceitos praticados

Estrutura `html`, `head` e `body`; metadados; títulos e parágrafos; entidades HTML; inclusão de CSS externo.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo HTML principal em um navegador moderno.
