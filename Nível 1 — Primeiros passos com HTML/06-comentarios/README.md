# 06 — Comentários

## Sobre o exercício

Documentar a estrutura de uma página pessoal e mostrar como comentários tornam o código mais legível.

## Tecnologias

- HTML5
- CSS3

## Estrutura

`comentarios.html` — página comentada
- `assets/css/style.css` — folha de estilos vinculada
- `assets/img/comentários.png` — imagem de referência

## Conceitos praticados

Comentários HTML; elementos semânticos `header`, `main` e `footer`; organização de seções com `div`; acessibilidade como critério de estrutura.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo HTML principal em um navegador moderno.
