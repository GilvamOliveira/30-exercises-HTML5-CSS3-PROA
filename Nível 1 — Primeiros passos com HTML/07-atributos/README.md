# 07 — Atributos HTML

## Sobre o exercício

Praticar atributos que configuram links e imagens, tornando o conteúdo navegável e acessível.

## Tecnologias

- HTML5
- CSS3

## Estrutura

`atributos.html` — exemplos práticos
- `assets/css/style.css` — folha de estilos vinculada
- `assets/img/example.jpg` e `assets/img/atributos.png` — imagens usadas e de referência

## Conceitos praticados

Atributos `href`, `src`, `alt`, `title`, `width` e `height`; links externos; boas práticas de texto alternativo.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo HTML principal em um navegador moderno.
