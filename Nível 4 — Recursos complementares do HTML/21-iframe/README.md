# 21 — Iframe

## Sobre o exercício

Incorporar um mapa externo no conteúdo de uma página usando um quadro incorporado.

## Tecnologias

- HTML5
- CSS3

## Estrutura

`iframe.html` — página do mapa
- `assets/css/style.css` — folha de estilos vinculada
- `assets/img/iframe.png` — imagem de referência

## Conceitos praticados

Elemento `iframe`; incorporação de OpenStreetMap; atributos de dimensão e acessibilidade; link alternativo para o mapa.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo HTML principal em um navegador moderno.
