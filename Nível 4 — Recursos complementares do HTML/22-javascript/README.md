# 22 — JavaScript no HTML

## Sobre o exercício

Fazer o primeiro uso de JavaScript dentro de uma página HTML para alterar conteúdo em resposta a cliques.

## Tecnologias

- HTML5
- CSS3

## Estrutura

`javascript.html` — página interativa
- `assets/css/style.css` — folha de estilos vinculada
- `assets/img/javascript.png` — imagem de referência

## Conceitos praticados

Tag `script`; eventos de botão; seleção e alteração de texto; separação entre marcação, estilo e comportamento.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo HTML principal em um navegador moderno.
