# 10 — Portfólio Pessoal

## Sobre o exercício

Apresentar um perfil profissional inicial com habilidades e links de presença digital.

## Tecnologias

- HTML5
- CSS3

## Estrutura

`index.html` — página do portfólio
- `assets/css/style.css` — folha de estilos vinculada
- `assets/img/Foto de Perfil.jpeg` e `portfólio.png`

## Conceitos praticados

Imagem de perfil; seções com títulos; listas de competências; links externos; estruturação de uma página de apresentação.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo HTML principal em um navegador moderno.
