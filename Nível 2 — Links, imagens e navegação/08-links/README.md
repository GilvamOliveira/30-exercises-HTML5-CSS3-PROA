# 08 — Links

## Sobre o exercício

Reunir links úteis para estudantes de tecnologia e aplicar uma imagem como elemento clicável.

## Tecnologias

- HTML5
- CSS3

## Estrutura

`links.html` — lista de recursos
- `assets/css/style.css` — folha de estilos vinculada
- `assets/img/W3Schools_logo.webp` e `hiperlink.png` — imagens

## Conceitos praticados

Âncoras; listas não ordenadas; URLs externas; imagem dentro de link; navegação para recursos de estudo.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo HTML principal em um navegador moderno.
