# 11 — Navegação entre Páginas

## Sobre o exercício

Criar um pequeno site multipágina com navegação consistente entre início, sobre e contato.

## Tecnologias

- HTML5
- CSS3

## Estrutura

`index.html` — página inicial
- `pages/sobre.html` e `pages/contato.html` — páginas internas
- `assets/css/style.css` e `assets/img/Logo site.jpg`

## Conceitos praticados

Elemento `nav`; links relativos; organização em subpastas; caminhos diferentes para páginas e recursos; reutilização de navegação.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo HTML principal em um navegador moderno.
