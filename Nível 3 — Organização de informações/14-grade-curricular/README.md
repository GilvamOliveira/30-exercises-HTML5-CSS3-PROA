# 14 — Grade Curricular

## Sobre o exercício

Representar uma grade semanal de aulas em formato tabular.

## Tecnologias

- HTML5
- CSS3

## Estrutura

`grade.html` — tabela da grade
- `assets/css/style.css` — folha de estilos vinculada
- `assets/img/tabela.png` — imagem de referência

## Conceitos praticados

Tabelas com `table`, `tr`, `th` e `td`; cabeçalhos de coluna; organização de dados por horário e dia.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo HTML principal em um navegador moderno.
