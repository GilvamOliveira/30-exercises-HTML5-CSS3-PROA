Seção 1 — Introdução

Cada seção desta página possui um id único e exclusivo. Diferente de uma class, que pode se repetir em vários elementos, um id só pode existir uma vez em toda a página HTML.

É justamente por ser único que o id pode ser usado como destino de um link âncora, como os do menu acima.

Seção 3 — Aplicações

Os ids também são muito usados em CSS e JavaScript quando queremos selecionar e estilizar (ou manipular) um único elemento específico da página, sem afetar outros.

Seção 4 — Conclusão

Resumindo: use class quando quiser reaproveitar um estilo em vários elementos, e use id quando precisar identificar um elemento único — como um destino de navegação interna ou um alvo específico de script.
