# 19 — ID e Âncoras

## Sobre o exercício

Usar identificadores únicos para criar navegação interna entre seções da mesma página.

## Tecnologias

- HTML5
- CSS3

## Estrutura

`id.html` — página com seções
- `assets/css/style.css` — estilos e rolagem
- `assets/img/identificação01.png` — imagem de referência

## Conceitos praticados

Atributo `id`; links de âncora; seletores por ID; menu fixo com `position: sticky`; rolagem suave com `scroll-behavior`.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo HTML principal em um navegador moderno.
