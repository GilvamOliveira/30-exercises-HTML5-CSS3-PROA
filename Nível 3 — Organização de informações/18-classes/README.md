# 18 — Classes CSS

## Sobre o exercício

Aplicar estilos reutilizáveis em cartões de cursos e diferenciar modalidades por classe.

## Tecnologias

- HTML5
- CSS3

## Estrutura

`classes.html` — lista de cursos
- `assets/css/style.css` — estilos dos cartões
- `assets/img/aulas.png` — imagem de referência

## Conceitos praticados

Atributo `class`; seletores de classe; combinação de classes; bordas, espaçamento e cores para estados reutilizáveis.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo HTML principal em um navegador moderno.
