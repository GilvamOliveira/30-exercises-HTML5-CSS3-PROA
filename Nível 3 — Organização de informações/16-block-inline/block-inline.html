Diferença entre Elementos Block e Inline

Este é um <div> (elemento de BLOCO). Ele sempre começa em uma nova linha e ocupa toda a largura disponível.

Este é um <p> (elemento de BLOCO). Assim como a div, cria uma quebra de linha antes e depois dele.

Este é um <h2> (elemento de BLOCO)

Já o <span> (INLINE) e o <strong> (INLINE) não quebram a linha, eles ficam no meio do texto, como este <a> (INLINE), ocupando apenas o espaço necessário.
